Install on Roku

  1. Build or download a ZIP configured for your publicly reachable HTTPS backend.
  2. Enable Roku Developer Mode and note the TV's IP address.
  3. From a browser on the same local network, open http://ROKU_IP and upload the ZIP using the Roku developer installer.
  4. Open the channel on Roku, then scan the pairing QR code with your phone.
